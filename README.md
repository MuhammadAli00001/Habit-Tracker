# Habit Tracker

A simple, clean website designed to help you build better habits, stay consistent, and track your daily progress.


## Overview

Habit Tracker is a personal habit-tracking website where you can create challenges, monitor your progress, and build a more consistent daily routine. It includes a monthly calendar and a timer to support your productivity.

This project was developed with assistance from **ChatGPT (AI)** using HTML, CSS, and JavaScript.


## Features

* **Habit Challenges** — Create and manage personal habit challenges.
* **Daily Progress Tracking** — Mark your daily progress and stay accountable.
* **Monthly Calendar** — View your progress throughout the month.
* **Focus Timer** — Use a timer to support focused work sessions.
* **Local Storage** — Save supported data in your browser without requiring a backend database.
* **Simple Interface** — A clean, minimal design focused on usability.


## Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Local Storage


## Getting Started

No installation or server setup is required for basic local use.

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

For online access, the website can also be published using GitHub Pages.

## Data and Privacy

The website uses browser Local Storage for supported saved data. Data is stored locally in the browser rather than in a project-hosted database. Clearing browser storage or changing browsers may remove or make saved data unavailable.
